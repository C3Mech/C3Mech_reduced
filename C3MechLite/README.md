## Structure of this directory

In the publications, we proposed 10 different reduced mechanisms based on C3MechLiteV4.0.1 based on the speedup ratio (Table 3 in the original publication and Table 2 in the corrigendum). **"Chemkin"** and **"Cantera"** folders contain these 10 mechanisms.

**"Table3_all_mechanisms"** contains all the different versions presented in Table 3 (Table 2 in the corrigendum). Note that the numbers of species and reactions for each mechanism correspond to the ones in the corrigendum.
